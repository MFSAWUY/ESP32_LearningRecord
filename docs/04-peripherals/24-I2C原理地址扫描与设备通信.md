# 24 I2C原理地址扫描与设备通信

[返回总目录](../../README.md) · 前置：先完成17章及正文注明的基础；下一步：总目录第25章。

## 接线与总线模型

前置GPIO、电阻和RC章节。OLED的SDA连接GPIO21、SCL连接GPIO22，GND共地，VCC按模块额定范围连接；本手册默认使用支持3.3V供电/逻辑的模块。四针的物理顺序可能不同，按丝印连接。SDA和SCL是开漏总线，设备主动拉低，释放线路后由上拉电阻拉高，多设备可以共享两根信号线。

## 地址和事务

7位地址后附加一位读写方向形成线上地址字节。Arduino Wire.beginTransmission接受7位地址，例如0x3C，不能随意传0x78。后续OLED库U8g2的setI2CAddress却需要左移一位，所以API的地址约定必须单独检查。

一次写事务包含START、地址与写方向、ACK、数据和ACK、STOP；读事务还涉及主机最后一个字节的NACK。地址ACK只证明有设备响应，不能分辨SSD1306、SH1106或同地址的其他设备，也不能证明传感器转换结果正确。

## 上拉与速度的物理解释

把总线近似为上拉电阻R和总电容C，可用V(t)=VDD(1−e^(−t/RC))描述上升沿。30%到70%阈值之间的时间差为RC·ln(0.7/0.3)≈0.8473RC。若R=4.7kΩ、C=100pF，估计上升时间约398ns；是否满足所选模式要对照I²C规范。电阻过大边沿太慢，过小则低电平时吸收电流I≈VDD/R过大。多个模块自带上拉并联后等效电阻减小，不能只看单块板的标值。

## 代码与操作

Wire.begin(21,22)显式指定引脚，Wire.setClock(100000)以100kHz起步，setTimeOut(50)限定总线操作等待。扫描器遍历非保留的常用7位地址8～119，每次发送空写事务，endTransmission结果为0则记录ACK。它不盲目向设备寄存器写入随机字节，减少对未知设备状态的影响。

先只接OLED运行，记录地址；再接SHT30，应该观察第二个独立地址。若没有设备，断电检查VCC/GND、SDA/SCL是否交换、连接是否松动。读到全部地址通常说明线路被错误拉低或库/硬件异常，而不是发现了上百个器件。总线超时后先查线路，再决定是否重新初始化。

## 练习与答案要点

把100kHz改为400kHz，比较显示刷新时间，只有模块规格和总线上升时间允许时才使用。理论速度提高4倍不表示应用总时间一定降为1/4，因为还包含显示处理和命令开销。两块同地址模块通常不能直接同时通信，可改地址、使用独立总线或I²C多路复用器；扫描程序本身不能解决地址冲突。

## 完整源码与双平台操作

完整工程：[examples/arduino/i2c_scan](../../examples/arduino/i2c_scan/README.md)；逐行源码：[main.cpp](../../examples/arduino/i2c_scan/src/main.cpp)；依赖与编译配置：[platformio.ini](../../examples/arduino/i2c_scan/platformio.ini)。示例固件在ESP32上运行，Windows/Linux负责构建、烧录和监视。主线为经典ESP32-D0WD、4 MB Flash；不假定存在PSRAM或可编程板载LED。

1. 按第04/05章完成工具链安装，在手册根目录打开PlatformIO终端；确认所选环境为esp32dev。
2. 断电按本章接线，检查3.3 V逻辑和共地。只接本例所需部件，避免其他实验复用同一引脚。
3. 如有include/config.example.h，复制为config.local.h并调整自己的配置。联网项目必须修改Wi-Fi凭据；无真实凭据时仍可编译，但不能连接你的网络。
4. 两个平台均执行以下构建与设备枚举命令：

```text
pio run -d examples/arduino/i2c_scan
pio device list
```

Windows PowerShell（枚举后输入实际端口）：

```powershell
pio device list
$port = Read-Host '输入枚举出的实际串口'
pio run -d examples/arduino/i2c_scan -t upload --upload-port $port
pio device monitor --port $port --baud 115200
```

Linux Bash（将设备路径换成实际枚举结果）：

```bash
pio device list
read -r -p '输入枚举出的实际串口: ' PORT
pio run -d examples/arduino/i2c_scan -t upload --upload-port "$PORT"
pio device monitor --port "$PORT" --baud 115200
```

烧录前关闭其他串口监视器。Windows检查CH340驱动和端口占用；Linux检查用户组/udev与文件权限，不用sudo运行整个开发环境，也不把设备改为777权限。按本章预期现象记录实际结果，错误分支也要验证，不能用编译成功代替电路和运行验收。
