# 08 单位、量纲、进制、位运算与数值表示

前置：第 06 章的单位概念。配套：[language_basics](../../examples/arduino/language_basics/)。返回：[总目录](../../README.md)。

## 先检查单位，再检查程序

常见嵌入式错误是数值正确而单位错误。1000 µs=1 ms，1000 ms=1 s；1 mA=$10^{-3}$ A，1 µF=$10^{-6}$ F。变量命名建议包含单位，例如 `period_ms`、`voltage_mv`，函数说明明确输入输出的尺度。计算中尽量统一为 SI 基本单位，显示时再转换。

频率 $f=1/T$：周期 2 ms 等于 0.002 s，对应 500 Hz，不是 0.5 Hz。功率 W 与能量 Wh 不同：持续 0.5 W 工作 2 h 消耗 1 Wh。电池 mAh 是电荷尺度，跨不同电压比较续航时需要换算能量并考虑效率。

量纲是快速校验工具。电流乘电阻得到电压，电压除电阻得到电流；把时间直接加到电压上没有物理意义。数值仿真输出“看起来合理”不能代替量纲检查。

## 从位置权重理解进制

十进制的 253 表示 $2\times10^2+5\times10+3$；二进制 `0b101101` 表示 $32+8+4+1=45$。十六进制每一位对应四个二进制位，`0x2D` 同样表示 45。一个字节的无符号范围是 0–255，N 位无符号范围为 $0\ldots2^N-1$。

寄存器和协议经常用位表示状态。假设位 0 表示采样有效，位 2 表示传感器异常：

```cpp
uint8_t flags = 0;
flags |= uint8_t(1U << 0);                  // 置位，不改变其他位
const bool valid = (flags & (1U << 0)) != 0;
flags &= uint8_t(~(1U << 2));               // 清除第 2 位
flags ^= uint8_t(1U << 0);                  // 翻转第 0 位
```

掩码检查使用 `&`，逻辑条件使用 `&&`；二者含义不同。移位数必须小于被移位类型的位宽，使用合适的无符号类型。不要把 `(1 << 31)` 当成所有平台都安全的写法，涉及 32 位最高位时可使用 `UINT32_C(1) << 31`。

## 补码、溢出与计时回绕

N 位补码的范围通常为 $-2^{N-1}\ldots2^{N-1}-1$。8 位的 `11111111` 按无符号解释是 255，按补码有符号解释是 -1；比特没变，类型解释变了。无符号整数运算按模 $2^N$ 回绕；C/C++ 的有符号溢出不能当作可靠的回绕技巧。

`millis()` 常用 32 位无符号毫秒计数，大约 49.7 天回绕一次。计时比较采用无符号差值：

```cpp
uint32_t now = millis();
if (uint32_t(now - last_ms) >= interval_ms) {
    last_ms = now;
    // 执行周期工作
}
```

例：旧值为 `0xFFFFFFF0`，新值为 `0x00000010`，模运算差值为 32 ms。前提是程序足够频繁检查，时间间隔小于计数器范围，并且没有跨越多次回绕；排序任意时间戳还需要更严格的半范围约束。直接比较 `now >= last_ms + interval_ms` 可能在加法回绕附近失效。

## 浮点和定点

多数十进制小数不能用有限二进制精确表示，类似十进制不能有限表示 1/3。因此浮点计算 `0.1+0.2` 的结果不应普遍用严格相等比较 0.3，而应根据测量尺度选绝对或相对容差。容差是工程要求，不是任意填一个很小的数字。

传感器温度可以用摄氏度浮点数，也可用整数毫摄氏度表示。例：23.456 ℃ 写作 23456 m℃。加法保持尺度，乘法需重新缩放，并用更宽中间类型避免溢出：

```cpp
int32_t temperature_mc = 23456;
int64_t scaled = int64_t(temperature_mc) * 1000;
// scaled 的单位变为千分之一 m℃，使用前必须说明尺度
```

协议中的字节序也需显式规定：16 位值 `0x1234` 大端传输为 `12 34`，小端为 `34 12`。不要直接发送带填充的 C 结构体作为长期协议，应逐字段编码，明确长度、符号、单位与版本。

练习：128×64 单色帧缓冲是多少字节？答案：1024，不是 8192 字节。115200 bit/s 的 8N1 UART 理想载荷上限是多少 byte/s？答案：每字节含 1 起始+8 数据+1 停止，共 10 位，因此 11520 byte/s，尚未扣应用协议开销。`uint16_t` 毫秒计数周期多长？答案：65.536 s。下一步：[09 连续与离散时间](09-嵌入式需要的函数微积分与离散时间.md)。参考：[C++ 整数语言参考](https://en.cppreference.com/w/cpp/language/types.html)、[Arduino millis](https://docs.arduino.cc/language-reference/en/functions/time/millis/)。
