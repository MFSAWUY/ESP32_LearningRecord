# 66 从面包板到PCB与产品化基础

## 原型成功之后还缺什么

前置：第03、11、30、48、53章。配套可回归固件：[serial_info](../../examples/arduino/serial_info/)、[diagnostics](../../examples/esp-idf/diagnostics/)、[硬件验收表](../../validation/HARDWARE_CHECKLIST.md)。本章交付的是设计方法与可执行验收流程；没有你的原理图和PCB文件时，不生成声称已经可生产的Gerber。

面包板适合低速验证，但接触电阻、回流路径、线长和电源瞬态都可能掩盖问题。先把原型转成明确的需求：电源输入、接口数量、最大负载、无线范围、工作环境、尺寸、升级与恢复方式。将必需功能和未来扩展分开，避免首板引入过多尚未验证电路。

## 电源设计计算

线性稳压器耗散P≈(Vin−Vout)I。例如5V到3.3V、300mA时P≈0.51W；小封装温升近似ΔT=PθJA，θJA受PCB铜皮和布局影响，不能直接套理想散热条件。Wi-Fi负载有瞬态峰值，平均电流正常不意味着电压不会跌落。

电容短时补偿近似ΔV=IΔt/C；若100mA额外负载持续100µs、允许下跌0.1V，理想C≥100µF。但ESR、走线电感、稳压器控制环和持续时间也决定效果，不能仅凭该式堆电容。每个电源域放置合适的高频去耦，并按芯片/模组官方参考设计核对。

## PCB布局与接口

优先采用认证模组降低射频设计复杂度，天线区域按模组要求保持净空，并考虑外壳、电池和金属结构的影响。射频净空不应被跨层走线、地铜或连接器破坏。数字回流应连续，电机大电流不要经过敏感模拟地回路。外接长线需按环境配置ESD、限流和保护。

将EN、BOOT、UART、3V3、GND或调试接口引出测试点。启动配置引脚的外设默认状态必须检查，避免接入模块后才发现无法启动。电源入口之间的防倒灌设计要明确；开发板上USB和外部电源能否并用不能泛化到自制板。

## 首板上电顺序

1. 断电测量电源对地阻值，目检极性、焊桥和元件值。
2. 使用限流电源，先不连接外部负载；确认3.3V和EN状态。
3. 烧录serial_info，核对Flash、复位原因和串口。
4. 逐一运行GPIO、I²C、网络及负载实验，每次只加入一个子系统。
5. 在最不利供电、网络重连和负载切换条件下测电压及温升。

Windows/Linux共用这些固件；电脑只是构建烧录工具，验收还必须有实际电气测量。给每块板记录序列号、硬件版本、固件版本和测试结果，避免仅凭“灯亮了”放行。

## 生产与维护

规划分区、工厂恢复、OTA回滚、凭据注入和设备身份。安全启动及Flash加密涉及不可逆或限制性配置，先在专用测试板验证，不放入普通批量烧录脚本。出厂测试只写测试范围允许的数据；返修时保留故障日志并防止泄露用户凭据。

练习：列出你的环境监测器五个出厂验收项目。参考：电源电流、传感器通信与合理值、显示边界、无线连接、重启持久化；每项应有阈值和可保存证据。来源：[乐鑫硬件设计指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32/)。下一步：第67章。
