## 术语对照

| 英文 | 中文与容易混淆的区别 |
|---|---|
| SoC / module / development board | 芯片系统/模组/开发板，集成层次不同 |
| firmware / framework / toolchain | 固件/开发框架/工具链，分别是产物、库和构建工具 |
| ROM / SRAM / Flash / PSRAM | 只读固化程序/片内易失内存/非易失存储/外接易失内存 |
| bootloader / partition | 引导程序/分区，负责启动选择与存储布局 |
| pull-up / floating / high impedance | 上拉/悬空/高阻，输入不接并不等于低电平 |
| open-drain / push-pull | 开漏/推挽，I²C通过上拉形成高电平 |
| ADC / DAC / PWM | 模数/数模/脉宽调制，PWM不是直接输出任意模拟电压 |
| interrupt / ISR / callback | 中断/中断服务/回调，回调不一定运行在ISR上下文 |
| task / queue / mutex | 任务/队列/互斥锁，不能用volatile替代同步 |
| latency / jitter / throughput | 延迟/抖动/吞吐量，平均吞吐正常不代表实时截止满足 |
| accuracy / precision / resolution | 准确度/精密度/分辨率，多小数位不代表更准 |
| calibration / filtering | 标定/滤波，去除随机波动不一定修复系统偏差 |
| broker / topic / QoS | MQTT代理/主题/服务质量，协议确认不等于业务完成 |
| rollback / watchdog / brownout | 回滚/看门狗/欠压，根因处理方式不同 |

## 基础与数学参考答案

LED计算应从供电、电流目标和正向压降出发，选择标准阻值后再次计算实际电流及电阻耗散；不要仅背330Ω。分压器接负载时，下臂电阻应与负载并联后计算，输入阻抗越小，测量越偏离空载值。

RC在一倍时间常数达到最终变化的约63.2%，并非完全充满。用5τ作为接近稳态的经验值还需看允许误差。采样频率高于信号最高频率两倍是理想带限条件；实际设计留余量并使用模拟抗混叠。70Hz在100Hz采样下与−30Hz的正弦样本相同，见math_lab的alias输出。

无符号计时差值可以跨越回绕，但并不允许任意长时间不检查；要保证时间尺度和比较方式匹配。浮点相等比较需根据误差量级设容差，而不是机械使用一个与量纲无关的固定epsilon。

## 编程与并发参考答案

返回局部数组指针是悬空指针，修复可由调用者提供缓冲区、使用拥有生命周期的对象或明确分配释放责任。const表达不可经该接口修改，不保证整个系统无人改变该对象；volatile约束编译器访问，不保证自增原子，也不建立任务间同步。

中断应尽快记录事件，耗时I/O交给任务。互斥锁保护一段共享资源生命周期，队列复制消息以明确所有权；传递指针时必须说明指向对象何时仍有效。只提高任务优先级可能饿死低优先级工作，不能当作通用性能优化。

## 综合项目参考答案

OLED错位首先查控制器和分辨率；字符缺失查字体字形及编码，而不是改I²C地址。MQTT离线补传应使用记录ID、确认位置和幂等写入，避免重连重复计数。执行器重启默认值需要业务分析，本书LED实验选择关闭；真实安全设计还需要硬件偏置和实际状态反馈。

低功耗应先测一轮活动时间和睡眠电流，在同一供电边界积分计算。RTC变量跨深睡不等于跨断电持久化。OTA下载成功还需校验、启动自检和确认有效；不可把“重启了”当作升级验收。

各章节附局部练习与参考要点，本页用于跨章节复习。建议闭卷解释三个问题：为什么需要这个机制、它解决什么故障、它的适用边界是什么。能改出效果只是第一步，能说明失败时的行为才具备独立开发能力。
