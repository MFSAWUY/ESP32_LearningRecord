## 从三层结构理解手中的板

**芯片（SoC）** 是执行指令并包含外设控制器的硅片，例如 ESP32-D0WD。**模组（module）** 将芯片、晶振、Flash、射频电路和天线等封装为便于焊接的模块，常见 WROOM 丝印写在金属屏蔽罩上。**开发板（development board）** 再加入 USB 转串口、电源稳压、按键和排针。购买页上的“ESP32-32 Type-C CH340”主要描述开发板连接方式，不能唯一确定模组修订或板载 LED 引脚。

本手册主线根据已知信息设为经典 ESP32-D0WD、4 MB SPI Flash、CH340、Type-C 接口。它支持经典 ESP32 的双核处理与无线功能，但程序不能仅凭商品标题假定引出了所有 GPIO。GPIO 丝印是逻辑编号，物理排针的第 21 个位置不是 GPIO21。

Type-C 仅说明接口外形。本板通过 CH340 将电脑 USB 数据转换为 ESP32 UART，USB 枚举为串口，并不因此具备可由 ESP32 固件任意编程的原生 USB 外设。断点调试需要对应的 JTAG 硬件；串口上传功能不是 JTAG 调试器。

## 各类存储器做什么

| 名称 | 主线已知/默认值 | 作用与限制 |
|---|---|---|
| ROM | 芯片标称 448 KB | 厂家固化的启动和基础代码，用户不把自己的程序烧进 ROM |
| SRAM | 芯片标称 520 KB | 运行中的数据、栈、堆及部分指令；系统会占用，应用可用量更小 |
| RTC SRAM | 16 KB | 低功耗相关区域，是否保留取决于休眠配置和复位类型 |
| SPI Flash | 用户提供为 4 MB | 掉电保存固件、分区表、配置和文件；有擦写寿命与擦除粒度 |
| PSRAM | 本书默认没有 | 外部伪静态 RAM，不能因为芯片支持就认为开发板已安装 |

字节是存储容量的常用单位，1 byte = 8 bits。厂商常用“4 MB”表示 Flash 规格，程序以字节报告；观察实际 Flash 容量要读取芯片信息。520 KB SRAM 也不是可连续 `malloc` 的 520 KB：缓存映射、无线协议栈、系统任务及不同能力的内存区域都影响可用空间。检查总空闲量之外还要关注最大连续块和最低剩余堆。

以 128×64 单色 OLED 为例，全帧缓冲需要 `128×64/8=1024` 字节，但显示库对象、字体和总线缓冲另占资源。每新增一项功能都应考虑资源预算，而不是把模块标称数字直接当应用预算。

## 引脚分类比记住引脚表更重要

- 电源：`3V3`、`5V/VIN`、`GND` 的含义不同；USB 输入 5 V 不代表 GPIO 能直接接 5 V。
- 启动配置：GPIO0、2、5、12、15 在复位时承担启动配置作用，外接电路可能改变启动行为。入门示例优先避开。
- Flash：通常使用 GPIO6–11；不要拿来接外设。GPIO16/17 是否可用还要核对具体模组是否连接 PSRAM。
- 输入专用：GPIO34–39 不能输出，且没有可用的软件内部上拉/下拉。浮空输入会产生不稳定结果。
- 串口：GPIO1/3 常承担烧录和日志，不作为第一组随意改接的引脚。
- 模拟：经典 ESP32 的 ADC2 与 Wi-Fi 存在资源限制，联网模拟采样优先使用 ADC1，并查驱动的具体限制。

本书将 I²C 示例默认设为 SDA=21、SCL=22，它们是工程约定而不是芯片不可更改的接线。多数外设信号可经 GPIO matrix 映射，但可映射不等于没有电气、速度或启动限制。

## 家族差异如何影响代码

| 系列 | 学习中需注意的差异 | 本书定位 |
|---|---|---|
| 经典 ESP32 | Xtensa；Wi-Fi、BLE、经典蓝牙；有传统 DAC 与触摸资源 | 主要验证目标 |
| ESP32-S3 | Xtensa；BLE、USB 和较丰富的内存/显示选项；不等同于经典蓝牙支持 | 屏幕、音频等拓展 |
| ESP32-C3 | RISC-V；单核；引脚和资源安排不同 | 小型节点移植 |
| ESP32-C6 | RISC-V；包含 802.15.4 与 2.4 GHz Wi-Fi 6 方向 | Thread/Zigbee 选学 |

同属 ESP32 家族，不代表 GPIO、DAC、蓝牙 API、双核假设都能直接照搬。移植时按“芯片能力→模组占用→板卡引出→框架支持”四层检查。型号表仅列学习路线中的代表，不是整个产品线的完整枚举。

## 实物确认与练习

记录屏蔽罩丝印、排针数量、USB 桥丝印及 BOOT/EN 按键位置。先在示例中打印芯片型号、核数、Flash 容量和可用堆，再与商品页比较；这只验证可读取的信息，不能自动证明屏幕型号或板上走线。

练习：GPIO34 能否用作按键输入？答案：可以，但无内部上拉，使用外部上拉或下拉并保证不浮空。4 MB Flash 是否意味着能放两个各 2 MB 的 OTA 应用？答案：不能直接这样分，还需启动程序、分区表、OTA 元数据、NVS 等空间。某 S3 例程写 GPIO48 点灯，能否照搬？答案：不能，芯片、板卡与 LED 类型都可能不同。
