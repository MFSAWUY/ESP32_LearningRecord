# 29 标定滑动平均与数字滤波

## 实验与数据处理顺序

前置ADC、平均数和离散时间。使用GPIO34读取电位器，输出原始毫伏、8点滑动平均和一阶低通三个CSV列。建议先记录原始数据再处理，便于判断滤波是否真正改善目标，而不是把重要变化平滑掉。处理链通常是有效性判断→物理量换算/校准→滤波→特征或控制，不将无效读数0混入平均。

## 标定推导

假设传感器读数x与参考量y在工作区间近似线性：y=ax+b。由两个参考点可得a=(y2−y1)/(x2−x1)，b=y1−ax1；x2=x1时不能求斜率。多点最小二乘的目标是最小化Σ(yi−axi−b)²，对a和b求偏导并令零可得直线拟合。拟合模型只在相近量程和环境下有意义，外推需重新评估。

使用未参与拟合的数据检验残差e=预测−参考，报告最大绝对误差、平均偏差及标准差。把拟合点完全对齐不等于泛化准确，参考仪器也有自己的误差和不确定度。

## 滑动平均的实现和延迟

N点均值y[k]=(1/N)Σx[k−i]。每次重算需要N次加法；环形缓冲保存旧值，用sum_new=sum_old−old+new可每次常数时间更新。代码开始时used<N，除以实际已有样本数，避免初始零值拉低结果。

等间隔采样T_s的N点对称平均对缓慢信号约引入(N−1)T_s/2延迟。本例N=8、T_s≈20ms，延迟约70ms。这个近似解释低频群延迟，不表示所有频率都同样延迟。对白噪声平均有效，对慢漂移或突发异常并不充分。

## 一阶低通的离散推导

连续模型τdy/dt+y=x。用后向欧拉近似dy/dt≈(y[k]−y[k−1])/Δt，并在当前时刻取y，可整理为y[k]=y[k−1]+α(x[k]−y[k−1])，α=Δt/(τ+Δt)。代码τ=0.1s，使用实际millis差值计算Δt；τ越大越平滑也越慢。另一种精确零阶保持系数1−exp(−Δt/τ)同样常见，需说明离散方法不同。

## 验收与练习

固定电位器时比较三列波动；突然转动时观察平均和低通滞后。数据已发生混叠时，数字滤波不能恢复正确原信号，需要采样前模拟带宽限制。练习：把τ改0.5s，绘制阶跃响应，约τ时达到最终变化的63.2%是连续一阶理想模型的预测。真实采样和量化存在偏差，应记录时间而不是凭肉眼判定。对单个巨大尖峰可比较中值滤波，注意不要为低噪声外观删除真实事件。

## 完整源码与双平台操作

完整工程：[examples/arduino/filter](../../examples/arduino/filter/README.md)；逐行源码：[main.cpp](../../examples/arduino/filter/src/main.cpp)；依赖与编译配置：[platformio.ini](../../examples/arduino/filter/platformio.ini)。示例固件在ESP32上运行，Windows/Linux负责构建、烧录和监视。主线为经典ESP32-D0WD、4 MB Flash；不假定存在PSRAM或可编程板载LED。

1. 按第04/05章完成工具链安装，在手册根目录打开PlatformIO终端；确认所选环境为esp32dev。
2. 断电按本章接线，检查3.3 V逻辑和共地。只接本例所需部件，避免其他实验复用同一引脚。
3. 如有include/config.example.h，复制为config.local.h并调整自己的配置。联网项目必须修改Wi-Fi凭据；无真实凭据时仍可编译，但不能连接你的网络。
4. 两个平台均执行以下构建与设备枚举命令：

```text
pio run -d examples/arduino/filter
pio device list
```

Windows PowerShell（枚举后输入实际端口）：

```powershell
pio device list
$port = Read-Host '输入枚举出的实际串口'
pio run -d examples/arduino/filter -t upload --upload-port $port
pio device monitor --port $port --baud 115200
```

Linux Bash（将设备路径换成实际枚举结果）：

```bash
pio device list
read -r -p '输入枚举出的实际串口: ' PORT
pio run -d examples/arduino/filter -t upload --upload-port "$PORT"
pio device monitor --port "$PORT" --baud 115200
```

烧录前关闭其他串口监视器。Windows检查CH340驱动和端口占用；Linux检查用户组/udev与文件权限，不用sudo运行整个开发环境，也不把设备改为777权限。按本章预期现象记录实际结果，错误分支也要验证，不能用编译成功代替电路和运行验收。
