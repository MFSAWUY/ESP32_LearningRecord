# 28 温湿度传感器与可靠数据采集

[返回总目录](../../README.md) · 前置：先完成17章及正文注明的基础；下一步：总目录第29章。

## 接线与测量链

前置I²C、位运算和误差概念。选用SHT30数字温湿度模块，3V3/GND供电，SDA21/SCL22，默认7位地址0x44；若模块地址脚配置不同，应修改常量。OLED与SHT30地址不同可共享总线，但要检查模块自带上拉的并联效果。不要把模拟输出的SHT3x-ARP与本例数字接口型号混淆。

一次测量包含发送转换命令、等待完成、读取字节、校验、换算和发布。通信成功不等于测量有效，传感器存在也不等于每次数据都可信。代码使用单次高重复性、无时钟拉伸命令0x2400，等待20ms后读取6字节，包含两组16位数据和各自CRC。

## 位组合与量纲推导

高字节H和低字节L组合为S=(H<<8)|L。依据数字传感器转换关系，T[°C]=−45+175·S_T/65535，RH[%]=100·S_RH/65535。举例S_RH=32768时湿度约50.0008%，不是把高字节直接当作整数百分比。温度公式中的−45是零点偏移，175是量程比例，不是可以随意替换的校准系数。

代码先将字节转换为无符号16位量再移位，避免符号扩展；计算时使用浮点常量，避免整数除法使结果大量变成0。显示两位小数只代表格式，不代表传感器具有0.01°C的准确度；分辨率、重复性和准确度是不同指标。

## CRC与错误处理

CRC初值0xFF，多项式0x31，每输入一字节先异或，再逐位移位并按最高位反馈。两个数据字节分别计算并与附带CRC比较。CRC用于发现传输错误，不防止恶意伪造，也不证明传感器未受到环境污染。任何ACK、长度或CRC错误均返回false，调用方输出valid=false，不给零温度替代失败。

把布尔有效标志与数字值一起发送，能使上位机区分真实0°C和读取失败。项目里可保存最后有效值及时间，但显示时必须附加“过期”状态；网络上传也不应把旧值偷偷当成新样本。

## 实验和误差分析

先运行扫描器，再运行测量，每秒观察一次输出。用手靠近但不直接触碰敏感开口，温湿度会缓慢变化。测量受空气流动、安装位置、PCB发热和传感器时间常数影响，与桌面温度计瞬间不同并不自动说明代码错误。远离ESP32稳压器和高温器件可降低局部自热影响。

验收还应包括断电后断开传感器再启动，确认输出错误且系统不崩溃。练习：每次成功采样增加seq，失败仍增加采样尝试序号，成功率=有效次数/尝试次数；答案要点是不要只用成功次数作分母。再加入一次重试，但每次都有限等待，避免坏设备阻塞全部任务。

## 完整源码与双平台操作

完整工程：[examples/arduino/sht30](../../examples/arduino/sht30/README.md)；逐行源码：[main.cpp](../../examples/arduino/sht30/src/main.cpp)；依赖与编译配置：[platformio.ini](../../examples/arduino/sht30/platformio.ini)。示例固件在ESP32上运行，Windows/Linux负责构建、烧录和监视。主线为经典ESP32-D0WD、4 MB Flash；不假定存在PSRAM或可编程板载LED。

1. 按第04/05章完成工具链安装，在手册根目录打开PlatformIO终端；确认所选环境为esp32dev。
2. 断电按本章接线，检查3.3 V逻辑和共地。只接本例所需部件，避免其他实验复用同一引脚。
3. 如有include/config.example.h，复制为config.local.h并调整自己的配置。联网项目必须修改Wi-Fi凭据；无真实凭据时仍可编译，但不能连接你的网络。
4. 两个平台均执行以下构建与设备枚举命令：

```text
pio run -d examples/arduino/sht30
pio device list
```

Windows PowerShell（枚举后输入实际端口）：

```powershell
pio device list
$port = Read-Host '输入枚举出的实际串口'
pio run -d examples/arduino/sht30 -t upload --upload-port $port
pio device monitor --port $port --baud 115200
```

Linux Bash（将设备路径换成实际枚举结果）：

```bash
pio device list
read -r -p '输入枚举出的实际串口: ' PORT
pio run -d examples/arduino/sht30 -t upload --upload-port "$PORT"
pio device monitor --port "$PORT" --baud 115200
```

烧录前关闭其他串口监视器。Windows检查CH340驱动和端口占用；Linux检查用户组/udev与文件权限，不用sudo运行整个开发环境，也不把设备改为777权限。按本章预期现象记录实际结果，错误分支也要验证，不能用编译成功代替电路和运行验收。
