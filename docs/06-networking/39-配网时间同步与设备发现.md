# 39 配网时间同步与设备发现

[返回总目录](../../README.md) · 前置：先完成17章及正文注明的基础；下一步：总目录第40章。

## 目标与状态流程

前置Wi-Fi、HTTP和非易失存储概念。实际产品不宜为每个家庭SSID重新编译。本例使用“没有保存凭据→临时热点及网页→保存→重启进入STA→同步时间”的流程，只需现有板卡及手机/电脑。GPIO27到GND的按键为可选恢复入口：按住按键并复位会清除本例network命名空间的保存内容。

首次运行建立ESP32-Setup热点，教学密码configure123；连接该热点后手动访问http://192.168.4.1。本例不是实现了DNS劫持的完整captive portal，不保证手机自动弹出配置页。输入2.4GHz SSID和密码，POST到/save，通过基本长度检查后保存并重启。

## 配置持久化与输入验证

Preferences在NVS中保存ssid和pass。SSID是字节长度受限的网络标识，中文UTF-8字符可能占多个字节；不能把32字节简单说成32个任意汉字。密码允许空字符串表示开放网络，否则本例接受8～63字节；这是示例的输入策略，不涵盖所有企业认证或特殊密钥形式。

程序把用户输入保存在待处理变量，在主循环写入并重启，避免在HTTP响应尚未发送时立即重启。错误凭据写入后设备会反复尝试已保存网络；按住GPIO27复位清除并重新配网。不要为了“自动恢复”在任意短暂断网就清空用户配置，这会使路由器重启演变为重新配置设备。

本例热点密码公开、HTTP表单不使用TLS、NVS未启用加密，所以它是受控近距离学习流程，不作为产品凭据保护方案。产品可以使用每设备独立配网密码、限定配网窗口和证明持有机制，并在安全章节评估Flash保护。演示结束后已保存凭据的设备只启动STA，不继续开放配置热点。

## 设备时间与时区

millis是启动后的相对毫秒计时，不能直接表示真实日期。SNTP根据网络时间设置系统时钟，time返回UTC时间基准，localtime按时区规则格式化。configTzTime("CST-8",...)使用POSIX时区字符串，符号方向与常见UTC+8写法相反，因此不能将"CST-8"解释成北京时间减8小时。示例对应中国标准时间，不含夏令时。

getLocalTime设置10ms等待预算，时钟尚未同步时输出unsynchronized，不能把1970年日期当作真实时间。SNTP依赖网络可达、DNS和服务响应；设备获得IP并不保证时钟已经可信。证书验证、日志时间排序和计划任务要明确如何处理未同步状态；本地周期控制应使用单调计时，避免墙上时间校正导致时间倒退。

## 漂移计算与发现机制

若时钟频率相对误差为20ppm，理想累计误差约20×10^-6×86400=1.728秒/天；温度和器件误差会改变结果，这不是对你的板卡精度保证。定期同步可限制长期漂移，但网络往返和调度也引入不确定度。

MDNS.begin("esp32-lab")允许支持mDNS的同一链路客户端尝试解析esp32-lab.local。mDNS不等于公共DNS，跨网段、客户端隔离或系统解析器不支持时可能失败，此时使用串口打印的实际IP。当前程序在STA阶段没有继续提供HTTP状态服务，因此解析名称成功不代表80端口一定可访问。

## 验收与练习

验证首次配网、断电后自动使用已保存凭据、错误密码后的手动恢复、未同步输出以及同步后的北京时间。练习：添加同步状态、最后成功同步时间和连接状态到OLED；答案要点是显示状态机而非启动时固定等待10秒后假定成功。可增加等待30秒未连接时进入受限恢复模式，但必须保留明确的用户触发条件与凭据生命周期说明。

## 完整源码与双平台操作

完整工程：[examples/arduino/time_provision](../../examples/arduino/time_provision/README.md)；逐行源码：[main.cpp](../../examples/arduino/time_provision/src/main.cpp)；依赖与编译配置：[platformio.ini](../../examples/arduino/time_provision/platformio.ini)。示例固件在ESP32上运行，Windows/Linux负责构建、烧录和监视。主线为经典ESP32-D0WD、4 MB Flash；不假定存在PSRAM或可编程板载LED。

1. 按第04/05章完成工具链安装，在手册根目录打开PlatformIO终端；确认所选环境为esp32dev。
2. 断电按本章接线，检查3.3 V逻辑和共地。只接本例所需部件，避免其他实验复用同一引脚。
3. 如有include/config.example.h，复制为config.local.h并调整自己的配置。联网项目必须修改Wi-Fi凭据；无真实凭据时仍可编译，但不能连接你的网络。
4. 两个平台均执行以下构建与设备枚举命令：

```text
pio run -d examples/arduino/time_provision
pio device list
```

Windows PowerShell（枚举后输入实际端口）：

```powershell
pio device list
$port = Read-Host '输入枚举出的实际串口'
pio run -d examples/arduino/time_provision -t upload --upload-port $port
pio device monitor --port $port --baud 115200
```

Linux Bash（将设备路径换成实际枚举结果）：

```bash
pio device list
read -r -p '输入枚举出的实际串口: ' PORT
pio run -d examples/arduino/time_provision -t upload --upload-port "$PORT"
pio device monitor --port "$PORT" --baud 115200
```

烧录前关闭其他串口监视器。Windows检查CH340驱动和端口占用；Linux检查用户组/udev与文件权限，不用sudo运行整个开发环境，也不把设备改为777权限。按本章预期现象记录实际结果，错误分支也要验证，不能用编译成功代替电路和运行验收。
