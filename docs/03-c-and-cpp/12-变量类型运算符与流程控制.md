## C++ 程序在板上如何开始

Arduino 工程使用 C++。框架在系统初始化后调用一次 `setup()`，之后反复调用 `loop()`；这两个名字是框架入口约定，不是 C++ 关键字。下面片段说明执行顺序，完整工程还包含串口命令和错误处理：

```cpp
#include <Arduino.h>
void setup() {
    Serial.begin(115200);       // 配置日志串口
}
void loop() {
    // 周期检查，完整工程采用 millis() 非阻塞调度
}
```

`#include` 在编译前包含声明，`Serial.begin` 是对象成员函数调用。花括号界定代码块，分号结束语句。注释解释为什么这么做，不参与运行。先能指出每个语句在哪个阶段执行，再开始增加业务逻辑。

## 类型决定解释方式与范围

变量是具有类型、存储和生命周期的对象。`uint32_t period_ms = 1000;` 为一个 32 位无符号整数初始化为 1000。固定宽度类型适合协议、位操作与硬件计时；`size_t` 适合数组长度和索引，位宽可能随电脑平台变化。不要把电脑上的 `long` 位宽假定为所有目标都相同。

| 类型 | 本书常见用途 | 要注意的问题 |
|---|---|---|
| `bool` | 是否连接、是否有效 | 条件状态不等于硬件引脚电压 |
| `uint8_t` | 字节、位标志 | 算术前可能先发生整数提升 |
| `uint32_t` | 毫秒计数、范围受控的计数 | 回绕是模运算，但仍需控制时间范围 |
| `int32_t` | 可为负的温度或误差 | 有符号溢出不可当安全技巧 |
| `float/double` | 需要小数的滤波与计算 | 精度、算力与误差需要权衡 |
| `char` | 文本或字符数组元素 | 文本以零结束时要为结束符留空间 |

`constexpr uint32_t kMinPeriodMs = 50;` 表示可在编译期使用的常量。`const` 表示经该名字不修改对象；它不自动把对象放进 ROM，也不等同于线程安全。初学阶段所有变量尽量明确初始化，避免把未初始化内存当作有效读数。

## 运算顺序与单位

整数除法丢弃小数部分：`5 / 2` 为 2，`5.0 / 2` 为 2.5。下面计算先乘后除，使用宽中间类型防止溢出：

```cpp
uint32_t elapsed_ms = 1234;
double elapsed_s = elapsed_ms / 1000.0;
uint32_t samples = 50000;
uint64_t bytes = uint64_t(samples) * 1024;
```

`uint64_t(samples)` 的转换在乘法之前发生；若写成 `uint64_t(samples * 1024)`，窄类型运算可能已经溢出。表达式复杂时使用括号明确意图，而不是让读者回忆全部运算符优先级。

比较使用 `==`，赋值使用 `=`。逻辑 `&&`、`||` 有短路行为：`ptr != nullptr && ptr->valid` 中左侧为假时不会访问右侧。位运算 `&`、`|` 不提供这种逻辑保护。用 `if (value >= low && value <= high)` 表示范围，不要写数学式 `low <= value <= high`。

## 选择与循环

`if/else` 根据条件选择路径；`switch` 适合有限状态。每个 case 结束后的 `break` 防止非预期落入下一分支。`for` 适合已知次数，`while` 适合条件控制。循环处理串口时既要考虑输入长度，也要限制一次处理的字节数，避免持续输入让其他任务长期得不到执行。

```cpp
for (size_t i = 0; i < 4; ++i) {
    // i 依次为 0、1、2、3；数组若有 4 项，i==4 已越界
}
if (period_ms < 50 || period_ms > 60000) {
    // 拒绝参数，保留此前有效配置
}
```

`delay(1000)` 便于第一次理解时序，但把响应串口和刷新显示都放在延时后会增加响应延迟。完整工程使用 `uint32_t(now-last_ms) >= period_ms` 决定是否到期，每次 `loop()` 都继续检查输入。

## 运行与观察

编译、上传 `language_basics` 并以 115200 打开串口。它明确打印 `source=synthetic`，数据为算法生成，不需要传感器。输入 `period 250` 改变输出周期；输入 `period -1` 或 `period 999999` 应拒绝，原周期保持不变。输入 `pause` 后周期输出停止，但 `status` 仍可响应，说明程序没有阻塞等待。

练习：把 `period_ms` 改成 16 位会限制哪些能力？答案：范围降至 65535，计时差与参数转换都需检查，不只是节省两个字节。`1000/60` 与 `1000.0/60` 有何区别？答案：前者为整数 16，后者约 16.6667。为什么不能用一个未初始化的 `bool ready;` 判断传感器是否就绪？答案：值没有有效来源，应从初始化和驱动返回状态设置。
